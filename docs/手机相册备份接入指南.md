# 手机相册自动备份接入指南

## 原理

归藏已内置 **WebDAV** 服务（`b72c388`），手机/电脑可通过 WebDAV 协议把相册文件传到 NAS，天然支持断点续传与目录浏览，无需安装专用 App 后端。

- **WebDAV 地址**：`http://<归藏IP>:<端口>/dav/`
- **账号**：归藏系统用户（用户名 + 密码）
- 挂载成功后，整个 NAS 文件系统可见（等同于文件管理的目录结构）

## 推荐目录规范

建议手机端备份到专用目录，便于与自动整理配合：

```
/photos/phone/{设备名}/  ← 各设备独立目录
  2026-08/xxx.jpg
  DCIM/xxx.mp4
```

> 提示：归藏的「自动整理」支持把接收目录按 日期/类型 归档，可将某个固定目录作为手机备份落点。

## 各平台客户端

### iPhone（iOS）

| 方式 | 说明 |
|---|---|
| 系统「文件」App | 浏览 → 连接服务器 → 输入 `http://<IP>:<端口>/dav/` + 账号密码，可手动拷贝相册 |
| PhotoSync（推荐） | App 内配置 WebDAV 目标，支持定时/自动备份、只备份新照片、按日期分目录 |
| Documents by Readdle | 文件管理 + 备份，支持 WebDAV |

### Android

| 方式 | 说明 |
|---|---|
| FolderSync（推荐） | 配置 WebDAV 账号后选「本地相册 → 远程目录」，可定时增量备份、双向同步 |
| CX 文件管理器 / Solid Explorer | 内置 WebDAV 协议，手动浏览上传 |
| 系统文件管理器 | 部分机型（如小米/华为）文件管理支持 WebDAV 挂载 |

### 电脑

- **Windows**：此电脑 → 映射网络驱动器 → `http://<IP>:<端口>/dav/`
- **macOS**：Finder → 前往 → 连接服务器 → `http://<IP>:<端口>/dav/`

## 注意事项

- 备份前确认磁盘空间充足（系统设置可开启「磁盘空间告警」）。
- 大目录首次备份建议用支持断点续传的客户端（PhotoSync / FolderSync）。
- 手机端建议在 WiFi 环境下自动备份，避免消耗流量。
