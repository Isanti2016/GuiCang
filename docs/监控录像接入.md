# 监控录像接入指南

## 功能简介

归藏支持把监控摄像头的录像文件接入 NAS，自动按「摄像头 / 日期」归档，网页端按摄像头选日期直接播放（支持拖动进度条，走 Range 流式）。

## 目录约定

| 目录 | 说明 |
|---|---|
| 接收目录 | 默认 `存储根/cameras/incoming`，可在 **系统设置 → 监控录像接收目录** 修改（留空恢复默认） |
| 归档目录 | 固定 `存储根/cameras/archive`，结构为 `{摄像头名}/{yyyy-MM-dd}/{文件名}` |

## 接入步骤

1. **放录像**：把摄像头录像文件（FTP 上传 / SD 卡拷出均可）放进接收目录。
   - 子目录名 = 摄像头名：`incoming/CAM01/xxx.mp4`、`incoming/客厅/xxx.mp4`
   - 直接放在接收目录根下的视频，归入 `default` 摄像头
   - 支持格式：mp4 / mov / avi / mkv / webm / m4v / flv / ts / m2ts / mts
2. **自动归档**：系统每 5 分钟扫描一次，把视频移动到 `archive/{摄像头}/{日期}/`，摄像头名自动注册（可在「监控录像」页补位置备注，如"客厅"）。
   - 日期优先取文件名内嵌 8 位数字（如 `CAM01_20260831_120000.mp4` → 2026-08-31），否则取文件修改时间
3. **网页查看**：打开 **存储 → 监控录像**，点摄像头 → 选日期 → 点录像播放。

## 常见录像机对接方式

- **FTP 上传型录像机**：录像机设置 FTP 上传到接收目录（或通过 NAS 的 WebDAV 挂载点上传）
- **SD 卡/U 盘**：拷贝到接收目录即可
- **RTSP 实时拉流**：需在录像机上开启录像 + 定时上传，或后续二期增加 FFmpeg 拉流转存（当前未实现）

## 注意事项

- 归档目录固定在存储根内，以保证文件索引与网页播放可用；请勿把归档目录移到存储根外。
- 摄像头重名文件（同名同日期）会自动追加 `_1`、`_2` 后缀，不会覆盖。
- 删除摄像头仅移除注册信息，**不影响**已归档的录像文件。
- 接收目录在存储根外也可以（如挂载的移动硬盘），归档时会跨卷复制后删除源文件。
